# First collection validation

Scope: 15 new original clock systems plus the existing five. This is not the final 18-new / 23-total milestone.

- Every catalog signature verified with the existing pinned ECDSA P-256 key.
- Both envelope and decoded payload fit the unchanged client limits.
- All 20 package and preview sizes/hashes match their signed records.
- Each new ZIP has 14 complete RGB565 135×240 glyphs and 14 PNG previews, with exact manifest resource hashes.
- All 15 new packs were accepted by the production Android validator on an Android 16 emulator.
- The unmodified 2.5.1 client accepted the 20-entry schema 1 candidate and rejected the unknown schema 2 candidate.
- 2.5.1 → 2.6 upgrade preserved test photo files/crop poses, draft, scene, preferences, favorite and signed saved-pack receipt.
- Signed schema migration, tampering rejection, rollback rejection, tag/category search and scroll retention passed on Android.
- Separate visual review accepted the 15 distinct static systems and checked digits/service glyphs. Nixie Laboratory is a stylized static glass-tube illustration.

This document records pre-publication checks. Live download/offline QA is recorded separately by the application project. Physical clocks and firmware were not modified.
